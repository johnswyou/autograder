# How it works

**Audience:** Instructors who need a clear model of the grading process.

**Prerequisites:** Complete the setup described in
[Getting started](getting-started.md).

**Outcome:** You can distinguish the system's automated work from the
instructor's required review and final approval.

This guide explains the grading pipeline and its responsibility boundaries.
For operational choices, see [Usage](usage.md); for precise command details,
see [Reference](reference.md).
