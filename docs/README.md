# Documentation

These guides help instructors operate Agentic Autograder and contributors
understand the repository.

- **New users:** Start with [Getting started](getting-started.md) to prepare a
  safe first run and review its results, then read
  [How it works](how-it-works.md) to understand how Claude sees a PDF and which
  decisions belong to Claude, Python, and the instructor.
- **Returning operators:** Use [Usage](usage.md) for operating decisions and
  [Reference](reference.md) for exact command, configuration, input, output,
  status, and resume contracts.
- **Contributors:** Read [Architecture](architecture.md) for the codebase and
  runtime guide.

Return to the project [README](../README.md) for the concise overview.
