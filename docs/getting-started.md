# Getting started

**Audience:** Instructors running Agentic Autograder for the first time.

**Prerequisites:** Python 3.10 or later, an Anthropic API key, and approval to
send assignment and student data to the service.

**Outcome:** You can prepare a first grading run and review its results before
releasing grades.

Begin with the repository setup and first-run workflow here. For the system
model, read [How it works](how-it-works.md); for every option, use the
[Reference](reference.md).
